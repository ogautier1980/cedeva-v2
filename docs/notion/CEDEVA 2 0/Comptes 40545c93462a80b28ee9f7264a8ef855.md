# Comptes

Il faudrait créer une petite page pour gérer les catégories en 3 colonnes:

- Entrées
- Sorties
- Hors bilan

Pour chaque catégorie, on peut indiquer le budget

![Capture d’écran 5.jpg](Comptes%204054-f855/Capture_decran_5.jpg)

Et également une page “BILAN” qui reprend les catégories ⬆️ en 3 parties:

- Entrées : toutes les catégories avec le total des entrées, puis total des sorties, puis bilan. A côté, en grisé, le budget estimé au départ. Comme ça le coordinateur voir si on est loin du compte ou pas
- Sorties : tout pareil

![Capture d’écran 6.jpg](Comptes%204054-f855/Capture_decran_6.jpg)

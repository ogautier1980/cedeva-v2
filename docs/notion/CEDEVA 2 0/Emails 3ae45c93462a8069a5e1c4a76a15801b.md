## Modèles

![Capture 2026-07-28 à 19.16.12.jpeg](Emails/Capture_2026-07-28_a_19.16.12.jpeg)

Je garderai les modèles :

- Confirmation d’inscription
- rappel fiche médicale
- Rappel paiement

Ces 3 là, on peut les modifier mais on ne peut pas les remplacer ou en créer un nouveau. Je vois que quand l’on crée un nouveau modèle, on peut faire un Confirmation de réservation. J’ai peut des doublons inutiles.

Par contre, si quelqu’un veut faire un modèle Excursion en fait ce qu’il veut.

Pour moi, les modèles généraux peuvent se retrouver dans toutes les activités. Pas besoin de modèles par activités.

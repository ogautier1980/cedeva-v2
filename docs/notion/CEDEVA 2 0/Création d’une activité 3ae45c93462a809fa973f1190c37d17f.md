## Etape 2 : paramétrage des dates

Là, c’est peut-être un peu plus technique, mais on doit trouver 2 fonctionnements. je pense qu’on en avait discuté.

- Inscriptions au jour le jour. Dans ce cas, rien de particulier. Tous les jours sont affichés sur le formulaire et les parents cochent les cases.
- Inscriptions à la semaine. Dans ce cas, le coordinateur doit le prévoir. Je que je propose: le lundi reste visible dans le formulaire. Mais, on lui glisse dessus, comme si c’était un sous-menu les jours qu’il va devoir englober. Voir première partie du schéma.
La parent ne sait alors cliquer que sur le lundi mais ça prévoit, dans ce cas-ci, 5 jours. Au final, le coordinateur, dans le mail de réception, lui, voit bien les 5 jours comme dans le tableau normal.

Pour les dates enfin, je simplifierai l’ajout d’une date avec un simple bouton : Ajouter une date et le système montre le calendrier. Pas “ajouter une date avant” et pas “ajoutre une date après).

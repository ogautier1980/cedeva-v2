Dans la logique des inscriptions:

1. Le parent remplit le formulaire
2. un mail arrive chez le parent pour confirmer que la demande a été faite
3. un mail arrive chez le coordinateur peut l’avertir d’une nouvelle inscription
4. Lorsque le coordinateur indique le montant à payer, un mail part chez le parent avec le montant à payer
5. C’est tout ;-)
